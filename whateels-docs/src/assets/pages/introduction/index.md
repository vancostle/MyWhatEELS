## Introduction
Welcome to the WhatEELS documentation. This section gives a first overview of the project, its purpose, and the type of workflows it supports for Electron Energy Loss Spectroscopy (EELS) analysis.

---

## What you will find here
The introduction pages are meant to help new users understand the context of WhatEELS before moving into the practical workflow pages.

In this section you can learn:

- what WhatEELS is designed to do,
- which kind of EELS datasets it focuses on,
- how the application is organized,
- and where to start if you are using it for the first time.

---

## Recommended first step
Start with the **WhatEELS** page to understand the main goals of the application and the typical analysis path, from loading DM3 or DM4 files to metadata inspection, clustering, fitting, and quantification.

After that, continue with the workflow pages to learn how each part of the application is used in practice.
